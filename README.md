# Synths

**Currently being reorganized from logic in other repos - working toward a structure something like:**

- `/dsp-core` contains DSP reusable DSP logic for writing Eurorack modules and other synthesizers
- `/modules` contains firmware for various Eurorack modules that use the above
- `/vcv-rack` is roughly parallel to `/modules`, bringing that logic to the [VCVRack](https://vcvrack.com) (mostly used for development)
